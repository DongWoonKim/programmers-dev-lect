# 자판기 만들기 (코틀린 기본 문법)

> 지금까지 배운 **변수 · 함수 · 조건문 · 반복문**만으로 동작하는 자판기를 만듭니다. 클래스도 객체도 쓰지 않습니다. **아래 Step을 순서대로 따라가면, 마지막 Step에서 프로그램이 완성됩니다.** 하나의 파일 안에서 함수를 여러 개 만들고, `main`에서 그 함수들을 조립하는 것이 목표입니다.

---

## 1. 무엇을 만드나요?

돈을 넣고 번호로 음료를 고르면 음료가 나오고 금액이 차감됩니다. 종료하면 잔돈을 돌려줍니다.

```
============== 자판기 ==============
[1]콜라 : 500, [2]사이다 : 500, [3]환타 : 300, [4]물 : 200, [5]돈 넣기, [6]종료
현재 금액 : 0
====================================
원하는 메뉴를 선택하시오.
5
돈을 넣으시오.
1000
============== 자판기 ==============
[1]콜라 : 500, [2]사이다 : 500, [3]환타 : 300, [4]물 : 200, [5]돈 넣기, [6]종료
현재 금액 : 1000
====================================
원하는 메뉴를 선택하시오.
1
콜라가 나왔습니다.
...
원하는 메뉴를 선택하시오.
6

잔돈 500원이 반환되었습니다.
```

## 2. 학습 목표

|개념|어디서 쓰나|
|---|---|
|`val` / `var`|바뀌지 않는 값과 바뀌는 값 구분하기 (`choice`는 `val`, `totalMoney`는 `var`)|
|`const val`|음료 가격 같은 상수 선언하기|
|함수 (`fun`)|메뉴 출력·입력받기·계산을 각각 함수로 나누기|
|매개변수와 반환값|`calcMoney(totalMoney, price)` 처럼 값을 주고받기|
|문자열 템플릿 (`$`)|`"현재 금액 : $totalMoney"`|
|`when`|메뉴 번호에 따라 갈래 나누기|
|`if ~ else`|잔돈이 부족한지 검사하기|
|`while (true)`|메뉴를 계속 반복해서 보여주기|
|`return`|반복문과 프로그램을 끝내기|
|`readln()`|사용자 입력 받기|

## 3. 핵심 개념

### (1) 큰 문제를 함수로 쪼개기

`main` 하나에 전부 몰아넣으면 금방 읽기 어려워집니다. **"하는 일 하나 = 함수 하나"** 로 쪼갭니다.

|함수|하는 일|
|---|---|
|`printMenu(totalMoney)`|메뉴와 현재 금액을 화면에 보여준다|
|`getChoice()`|사용자에게 메뉴 번호를 입력받아 돌려준다|
|`getMoney()`|사용자에게 넣을 금액을 입력받아 돌려준다|
|`calcMoney(totalMoney, price)`|금액을 차감한 결과를 돌려준다|
|`calcMoneyException()`|잔돈 부족 메시지를 보여준다|
|`main()`|위 함수들을 순서대로 불러서 자판기를 굴린다|

> 값을 **보여주기만** 하는 함수는 반환값이 없고(`Unit`), 값을 **돌려주는** 함수는 반환 자료형을 적습니다.

### (2) 반복 + 분기의 조합

자판기는 "메뉴를 보여주고 → 입력을 받고 → 처리하고 → 다시 메뉴로" 를 계속 되풀이합니다.

```kotlin
while (true) {          // 종료를 고를 때까지 무한 반복
    printMenu(totalMoney)
    val choice = getChoice()
    when (choice) {     // 입력한 번호에 따라 갈래를 나눈다
        ...
    }
}
```

`while (true)`는 스스로 멈추지 않습니다. **`return`으로 빠져나오는 갈래를 반드시 만들어야** 합니다.

### (3) 사용자 입력 받기

```kotlin
val line = readln()         // 사용자가 입력한 한 줄을 String 으로 읽는다
val number = line.toInt()   // 문자열을 Int 로 바꾼다
```

두 줄을 합치면 `readln().toInt()` 입니다. (자바의 `Scanner` + `nextInt()` 자리)

## 5. Step by Step

각 Step에 **목표 / 할 일 / 힌트 / 확인 방법**이 있습니다.

---

### Step 1. 상수 선언과 메뉴 출력

**목표**: 음료 가격을 상수로 선언하고, 메뉴를 출력하는 함수를 만든다.

**할 일**

1. 파일 최상위에 `const val` 로 `COKE`, `CIDER`, `FANTA`, `WATER` 를 선언한다.
2. `printMenu(totalMoney: Int)` 함수를 만든다.
3. 현재 금액은 **문자열 템플릿**으로 출력한다.

**힌트**

```kotlin
const val COKE = 500
const val CIDER = 500
const val FANTA = 300
const val WATER = 200

fun printMenu(totalMoney: Int) {
    println("============== 자판기 ==============")
    println("[1]콜라 : 500, [2]사이다 : 500, [3]환타 : 300, [4]물 : 200, [5]돈 넣기, [6]종료")
    println("현재 금액 : $totalMoney")
    println("====================================")
}
```

> `const val` 은 값을 바꿀 수 없는 상수입니다. 가격처럼 프로그램 내내 고정된 값에 씁니다.
> 반환값이 없으므로 반환 자료형(`Unit`)은 생략합니다.

**확인**: `main` 에서 `printMenu(0)` 을 불러 메뉴가 출력되면 성공.

---

### Step 2. 입력받는 함수 두 개

**목표**: 메뉴 번호와 넣을 금액을 각각 입력받는 함수를 만든다.

**할 일**

1. `getChoice(): Int` — 안내 문구를 출력하고, 입력받은 값을 `Int` 로 돌려준다.
2. `getMoney(): Int` — 같은 방식으로 금액을 돌려준다.

**힌트**

```kotlin
fun getChoice(): Int {
    println("원하는 메뉴를 선택하시오.")

    return readln().toInt()
}
```

> 값을 돌려주는 함수이므로 반환 자료형 `: Int` 를 반드시 적어야 합니다.
> `getMoney()` 는 안내 문구만 바꿔서 똑같이 만들면 됩니다.

**확인**: `println(getChoice())` 로 입력한 숫자가 그대로 출력되면 성공.

---

### Step 3. 금액 계산 함수

**목표**: 금액을 차감한 결과를 돌려주는 함수와, 잔돈 부족을 알리는 함수를 만든다.

**할 일**

1. `calcMoney(totalMoney: Int, price: Int): Int` — 차감 결과를 돌려준다.
2. `calcMoneyException()` — "잔돈이 부족합니다." 를 출력한다.

**힌트**

```kotlin
fun calcMoney(totalMoney: Int, price: Int): Int {
    return totalMoney - price
}
```

> 이 함수는 **계산만** 합니다. 부족한지 판단하거나 금액을 실제로 바꾸는 일은 하지 않습니다.
> 현재 금액이 300이고 콜라가 500이면 결과는 `-200` 입니다. 이 **음수**가 "잔돈 부족"의 단서가 됩니다.
> 한 줄짜리이므로 `fun calcMoney(totalMoney: Int, price: Int): Int = totalMoney - price` 로 줄여 써도 좋습니다.

**확인**: `println(calcMoney(300, 500))` 이 `-200` 을 출력하면 성공.

---

### Step 4. 메뉴 반복 루프 만들기

**목표**: 메뉴가 계속 반복해서 나오도록 `main` 의 뼈대를 만든다.

**할 일**

1. `main` 안에 현재 금액을 담을 변수를 선언한다. → 값이 계속 바뀌므로 `var`
2. `while (true)` 로 반복하면서 `printMenu` 와 `getChoice` 를 부른다.
3. 아직 `when` 은 없어도 된다. 입력받은 번호를 출력만 해 본다.

**힌트**

```kotlin
fun main() {
    var totalMoney = 0

    while (true) {
        printMenu(totalMoney)
        val choice = getChoice()
        println("입력한 번호: $choice")     // 임시 확인용
    }
}
```

> `totalMoney` 는 계속 바뀌므로 `var`, `choice` 는 그 회차에서 바뀌지 않으므로 `val` 입니다.
> 지금은 끝낼 방법이 없어 무한 반복됩니다. **Ctrl + C 로 멈추세요.** 다음 Step에서 종료를 만듭니다.

**확인**: 번호를 입력할 때마다 메뉴가 다시 나오면 성공.

---

### Step 5. `when` 으로 음료 구매 처리하기

**목표**: 1~4번을 골랐을 때 음료가 나오고 금액이 차감되게 한다.

**할 일**

1. `when (choice)` 로 갈래를 나눈다.
2. 각 갈래에서 `calcMoney` 로 결과를 구한다.
3. `if` 로 결과가 **음수인지** 검사한다.
   - 음수면 → `calcMoneyException()`
   - 아니면 → `totalMoney` 를 결과로 바꾸고 음료 메시지 출력

**힌트**

```kotlin
var result = -1

when (choice) {
    1 -> {
        result = calcMoney(totalMoney, COKE)
        if (result < 0) {
            calcMoneyException()
        } else {
            totalMoney = result
            println("콜라가 나왔습니다.")
        }
    }
    2 -> {
        // 사이다도 같은 방식으로
    }
    // 3번 환타, 4번 물도 같은 방식으로
}
```

> **주의**: `totalMoney = result` 는 잔돈이 부족하지 **않을 때만** 해야 합니다.
> 먼저 대입해 버리면 돈이 음수가 되어 버립니다.
> 자바의 `switch` 와 달리 `break` 를 쓰지 않습니다. 맞는 갈래 하나만 실행되고 끝납니다.
> 갈래에서 실행할 코드가 여러 줄이면 중괄호 `{ }` 로 묶습니다.

**확인**: 금액이 0인 상태로 1번을 고르면 "잔돈이 부족합니다." 가 나오면 성공.

---

### Step 6. 돈 넣기 · 종료 · 잘못된 입력

**목표**: 5번, 6번, 그리고 그 외 입력을 처리해 프로그램을 완성한다.

**할 일**

1. `5 ->` : `getMoney()` 로 받은 금액을 `totalMoney` 에 **더한다**.
2. `6 ->` : 잔돈 반환 메시지를 출력하고 `return` 으로 프로그램을 끝낸다.
3. `else ->` : "잘 못 입력하셨습니다. 다시 입력해주세요." 를 출력한다.

**힌트**

```kotlin
5 -> totalMoney += getMoney()
6 -> {
    println("\n잔돈 ${totalMoney}원이 반환되었습니다.")
    return
}
else -> println("잘 못 입력하셨습니다. 다시 입력해주세요.")
```

> 실행할 코드가 한 줄이면 중괄호 없이 `->` 뒤에 바로 씁니다.
> `\n` 은 줄바꿈입니다.
> `${totalMoney}원` 에서 중괄호가 필요한 이유를 생각해 보세요. `$totalMoney원` 이라고 쓰면 왜 안 될까요?
> `return` 은 `main` 을 끝내는 것이고, 그 결과로 `while (true)` 도 함께 끝납니다.

**확인**: 돈 넣기 → 구매 → 종료가 모두 동작하면 성공!

## 8. (선택) 도전 과제

1. **숫자가 아닌 입력 막기**
   지금은 `abc` 를 입력하면 프로그램이 예외로 죽습니다.
   `toIntOrNull()` 과 엘비스 연산자(`?:`)를 써서 잘못된 입력이면 `-1` 을 돌려주게 바꿔 보세요.
   ```kotlin
   return readln().toIntOrNull() ?: -1
   ```

2. **중복 줄이기**
   1~4번 갈래의 코드가 음료 이름과 가격만 다르고 거의 같습니다.
   `buy(totalMoney: Int, price: Int, name: String): Int` 함수 하나로 묶어 보세요.
   `when` 이 아래처럼 짧아집니다.
   ```kotlin
   1 -> totalMoney = buy(totalMoney, COKE, "콜라")
   ```

3. **판매 기록**
   음료를 몇 개 팔았는지 세어서, 종료할 때 총 판매 개수와 매출을 함께 출력해 보세요.

4. **재고 넣기**
   음료마다 남은 수량을 `var` 로 두고, 0이면 "품절입니다." 를 출력하게 해 보세요.

5. **금액 단위 검사**
   100원 단위가 아닌 금액(예: 350)을 넣으면 "100원 단위로 넣어 주세요." 를 출력하고 받지 않게 해 보세요. (`%` 연산자 활용)

6. **거스름돈 내역**
   종료할 때 잔돈을 500원 / 100원 몇 개로 돌려주는지 계산해 출력해 보세요. (`/` 와 `%` 활용)
