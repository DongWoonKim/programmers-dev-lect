# 회원 관리 프로그램 만들기 (코틀린 2차원 배열)

> 2차원 배열에 회원 정보를 저장하고 추가·조회·수정·삭제(CRUD)하는 콘솔 프로그램을 만듭니다. 지금까지 배운 **변수 · 함수 · 조건문 · 반복문 · 배열**만 씁니다. 클래스도 리스트도 쓰지 않습니다. **아래 Step을 순서대로 따라가면, 마지막 Step에서 프로그램이 완성됩니다.**

---

## 1. 무엇을 만드나요?

시작하면 요금제를 고르고(정원이 정해짐), 메뉴가 반복해서 나옵니다.

```
[요금제를 선택하세요]
[1]Lite : 10명 [2]Basic : 20명 [3]Premium : 30명
> 2

[수행할 업무를 선택하세요 - 현재 회원수 : 0/20]
[1]회원추가 [2]회원조회(메일) [3]회원조회(이름)
[4]회원전체조회 [5]회원정보 수정 [6]회원삭제
[7]프로그램 종료
> 1

이름을 입력하세요.
> 홍길동
이메일을 입력하세요.
> hong@a.com
연락처를 입력하세요.
> 010-1111-1111
회원이 등록되었습니다.
```

## 3. 학습 목표

|개념|어디서 쓰나|
|---|---|
|2차원 배열 만들기|`Array(정원) { Array(3) { "" } }` — **`new` 없이** 만든다|
|인덱스 접근|`members[i][0]`, `members[i][1]`, `members[i][2]`|
|파일 최상위 `var`|자바의 `static` 자리. 여러 함수가 함께 쓰는 상태|
|`val` / `var` 구분|`members`는 `val`, `memberCnt`는 `var`|
|문자열 비교 `==`|자바의 `equals` 자리. **코틀린은 `==` 로 내용 비교**|

|`return` / `-1` 관례|"못 찾았다"를 값으로 돌려주기|

## 4. 핵심 개념

### (1) 2차원 배열로 회원 저장 — 코틀린에는 `new` 가 없다

회원 한 명 = 한 줄(행), 속성 3개 = 칸(열)으로 표현합니다.

```
         열0(이름)   열1(이메일)        열2(연락처)
행0 →   "홍길동"    "hong@a.com"      "010-1111-1111"
행1 →   "김철수"    "kim@b.com"       "010-2222-2222"
 ...
```

자바와 코틀린을 나란히 보면:

```java
// 자바
String[][] members = new String[정원][3];
```

```kotlin
// 코틀린
val members = Array(정원) { Array(3) { "" } }
```

- 코틀린에는 **`new` 키워드 자체가 없습니다.** `Array(...)` 처럼 생성자를 바로 호출합니다.
- `Array(정원) { ... }` — 중괄호 안의 결과로 각 칸을 채웁니다. 각 칸이 다시 `Array(3) { "" }`, 즉 **빈 문자열 3칸짜리 배열**입니다.
- 자바는 채우지 않은 칸이 자동으로 `null` 이지만, 코틀린은 **빈 값을 무엇으로 채울지 내가 정해야** 합니다. 여기서는 `""`(빈 문자열)로 채웁니다.

> 💡 **왜 `null` 이 아니라 `""` 인가?**
> `arrayOfNulls<String>(3)` 을 쓰면 자료형이 `Array<String?>` 이 되어, 값을 쓸 때마다 `?.` 나 `!!` 를 붙여야 합니다.
> `""` 로 채우면 자료형이 `Array<String>` 이라 null 걱정 없이 그냥 쓸 수 있습니다. 이 과제에서는 이 방식을 씁니다.

- `members[i][0]` = i번째 회원 이름
- `members[i][1]` = i번째 회원 이메일
- `members[i][2]` = i번째 회원 연락처

### (2) 파일 최상위 `var` 로 상태 공유

여러 함수가 함께 쓰는 값은 파일 **최상위**에 선언합니다. 자바의 `static` 변수 자리입니다.

```kotlin
var totalCnt = 0    // 정원 (요금제로 결정)
var memberCnt = 0   // 현재 회원 수 (= 다음에 채울 칸의 인덱스)
```

`memberCnt` 는 "현재 인원 수"이자 "다음에 회원을 넣을 빈 칸의 위치"라는 두 의미를 함께 가집니다.

> 코틀린은 클래스 밖에 변수와 함수를 바로 선언할 수 있어서 `static` 이라는 키워드가 필요 없습니다.
> 값이 계속 바뀌므로 `var`, 배열 자체는 바뀌지 않으므로 `members` 는 `val` 입니다.
> (`val` 이어도 `members[0][0] = "홍길동"` 처럼 **안의 값은 바꿀 수 있습니다.** H_array 참고!)

### (3) 선형 검색 패턴 — 문자열 비교는 `==`

이메일/이름으로 찾을 때는 처음부터 등록된 인원까지 돌면서 비교합니다.

```kotlin
for (i in 0 until memberCnt) {
    if (email == members[i][1]) {
        // 찾음!
    }
}
```

> ⚠️ **자바와 가장 크게 다른 점**
> 자바에서는 문자열 비교에 반드시 `.equals()` 를 써야 했습니다. `==` 는 주소를 비교하니까요.
> **코틀린의 `==` 는 내부적으로 `equals()` 를 호출합니다.** 그래서 문자열도 `==` 로 비교하면 됩니다.
> (주소를 비교하고 싶으면 `===` 를 씁니다. 쓸 일은 거의 없습니다.)

**"못 찾았다"를 표현하는 관례**: 인덱스를 돌려주는 함수는 못 찾았을 때 **`-1`** 을 돌려줍니다. 배열 인덱스는 절대 음수가 될 수 없으니, `-1` 은 "그런 건 없다"는 뜻으로 안전하게 쓸 수 있습니다.

### (4) 삭제 후 "당기기"

배열은 크기를 바꿀 수 없고 중간을 비울 수도 없으므로, 삭제한 칸 **뒤의 회원들을 한 칸씩 앞으로** 옮깁니다.

```
삭제 전: [A][B][C][D]      B를 삭제
당기기:  [A][C][D][ ]      C,D가 한 칸씩 앞으로
```

|파일|역할|
|---|---|
|`J_member_manager.kt`|**하나의 파일**에 최상위 변수 · 함수들 · `main` 을 모두 작성|

|함수|역할|

> 코틀린 버전에서는 **`findIndex` 함수 하나로 전부 해결**합니다. "찾기"라는 같은 일을 다섯 번 쓰지 않는 것이 이 과제의 숨은 목표입니다.

## 6. Step by Step

각 Step에 **목표 / 할 일 / 힌트 / 확인 방법**이 있습니다.

---

### Step 1. 요금제 선택 + 메뉴 골격

**목표**: 요금제를 고르면 그만큼 배열을 만들고, 메뉴가 반복 출력되며 7번이면 종료된다.

**할 일**

1. 파일 최상위에 `totalCnt`, `memberCnt` 를 `var` 로 선언한다.
2. `printPricePlan(): Int` — 요금제 안내를 출력하고 선택 번호(1~3)를 반환한다.
3. `main()` — 선택값 `num` 으로 배열을 만들고 `totalCnt` 를 정한다.
4. `printMenu(): Int` — 현재인원/정원과 업무 메뉴를 출력하고 선택 번호를 반환한다.
5. `while (true)` + `when` — 각 갈래는 비워 두고, `7` 에서 `return`, `else` 는 안내 문구.

**힌트**

```kotlin
var totalCnt = 0
var memberCnt = 0

fun printPricePlan(): Int {
    println("[요금제를 선택하세요]")
    println("[1]Lite : 10명 [2]Basic : 20명 [3]Premium : 30명")
    print("> ")
    return readln().toInt()
}

fun printMenu(): Int {
    println("\n[수행할 업무를 선택하세요 - 현재 회원수 : $memberCnt/$totalCnt]")
    println("[1]회원추가 [2]회원조회(메일) [3]회원조회(이름)")
    println("[4]회원전체조회 [5]회원정보 수정 [6]회원삭제")
    println("[7]프로그램 종료")
    print("> ")
    return readln().toInt()
}

fun main() {
    val num = printPricePlan()
    totalCnt = num * 10
    val members = Array(totalCnt) { Array(3) { "" } }

    while (true) {
        when (printMenu()) {
            1 -> { /* Step 2 */ }
            2 -> { /* Step 3 */ }
            3 -> { /* Step 4 */ }
            4 -> { /* Step 5 */ }
            5 -> { /* Step 6 */ }
            6 -> { /* Step 7 */ }
            7 -> {
                println("이용해주셔서 감사합니다.")
                return
            }
            else -> println("올바른 번호를 입력하세요.")
        }
    }
}
```

> `printMenu()` 는 매개변수가 없습니다. `memberCnt` 와 `totalCnt` 가 **최상위 변수**라 어디서든 그냥 읽을 수 있기 때문입니다.
> `when` 에는 `break` 를 쓰지 않습니다. 맞는 갈래 하나만 실행되고 끝납니다.
> `readln()` 은 한 줄을 통째로 읽습니다. **자바 `Scanner` 의 `nextInt()` + `nextLine()` 버퍼 문제가 없습니다.**

**확인**: 요금제 선택 후 메뉴가 반복되고, 7을 누르면 종료되면 성공.

---

### Step 2. 회원 추가

**목표**: 이름·이메일·연락처를 받아 배열에 저장한다. 정원 초과와 이메일 중복은 막는다.

**할 일**

1. `memberCnt == totalCnt` 이면 "회원이 꽉 찼습니다." 출력 후 `return`.
2. 이름·이메일·연락처를 입력받는다.
3. 이미 있는 이메일이면 "이미 존재하는 회원입니다." 출력 후 `return`. (Step 3에서 만들 `findIndex` 를 미리 써도 되고, 지금은 반복문으로 직접 검사해도 됩니다.)
4. `members[memberCnt]` 에 세 값을 채우고 `memberCnt++`.

**힌트**

```kotlin
fun addMember(members: Array<Array<String>>) {
    if (memberCnt == totalCnt) {
        println("회원이 꽉 찼습니다.")
        return
    }

    println("이름을 입력하세요.")
    val name = readln()
    println("이메일을 입력하세요.")
    val email = readln()
    println("연락처를 입력하세요.")
    val phone = readln()

    // 중복 검사 (Step 3의 findIndex 를 쓰면 한 줄로 줄어듭니다)
    for (i in 0 until memberCnt) {
        if (email == members[i][1]) {
            println("이미 존재하는 회원입니다.")
            return
        }
    }

    members[memberCnt][0] = name
    members[memberCnt][1] = email
    members[memberCnt][2] = phone
    memberCnt++
    println("회원이 등록되었습니다.")
}
```

> **`return` 으로 일찍 빠져나오기**: 잘못된 상황을 함수 앞부분에서 걸러내고 `return` 하면, 뒤쪽 코드가 `if` 안으로 깊게 들어가지 않아 읽기 쉽습니다.
> **반복 범위에 주의**: `0 until memberCnt` 입니다. `totalCnt` 까지 돌면 아직 안 채운 `""` 칸까지 비교하게 됩니다.
> `members` 는 `val` 로 받았지만 `members[i][0] = ...` 처럼 **안의 값은 바꿀 수 있습니다.**

**확인**: 추가 후 전체 조회(Step 5)에서 보이고, 같은 이메일로 또 추가하면 거부되면 성공.

---

### Step 3. 검색 함수 만들기 + 이메일로 조회

**목표**: **검색을 함수 하나로 만들고**, 그것을 이용해 이메일 조회를 완성한다.

**할 일**

1. `printMember(member: Array<String>)` — 회원 한 명을 한 줄로 출력한다.
2. `findIndex(members, col, value): Int` — `col` 번째 열에서 `value` 를 찾아 인덱스를 반환. 없으면 `-1`.
3. `selectEmail(members)` — 이메일을 입력받아 `findIndex` 로 찾고, 결과를 출력한다.

**힌트**

```kotlin
fun printMember(member: Array<String>) {
    println("[이름] ${member[0]}, [이메일] ${member[1]}, [연락처] ${member[2]}")
}

fun findIndex(members: Array<Array<String>>, col: Int, value: String): Int {
    for (i in 0 until memberCnt) {
        if (value == members[i][col]) {
            return i        // 찾는 즉시 인덱스를 돌려주고 함수 끝
        }
    }
    return -1               // 끝까지 못 찾았다
}

fun selectEmail(members: Array<Array<String>>) {
    println("이메일을 입력하세요.")
    val email = readln()

    val idx = findIndex(members, 1, email)
    if (idx == -1) {
        println("찾으시는 정보가 없습니다.")
        return
    }
    printMember(members[idx])
}
```

> `members[idx]` 는 **행 하나(배열 하나)** 입니다. 그래서 `printMember` 의 매개변수 자료형이 `Array<String>` 입니다.
> `col` 에 `1` 을 넘기면 이메일 열, `0` 을 넘기면 이름 열을 검색합니다. **같은 함수를 열 번호만 바꿔 재사용**하는 것이 핵심입니다.
> Step 2의 중복 검사도 이제 한 줄로 줄일 수 있습니다: `if (findIndex(members, 1, email) != -1) { ... }`

**확인**: 등록한 이메일로 조회하면 정보가 나오고, 없는 이메일은 안내 메시지가 나오면 성공.

---

### Step 4. 이름으로 조회

**목표**: Step 3의 `findIndex` 를 그대로 쓰되, 검색할 **열 번호만** 바꾼다.

**할 일**: `selectEmail` 을 복사해 안내 문구와 `findIndex` 의 `col` 인자만 `0` 으로 바꾼다.

**힌트**

```kotlin
val idx = findIndex(members, 0, name)   // 1 -> 0 (이름 열)
```

**확인**: 이름으로 조회가 되면 성공.

> 같은 이름이 여러 명이면 어떻게 될까요? 지금은 **처음 찾은 한 명만** 나옵니다. (도전 과제에서 개선)

---

### Step 5. 전체 조회

**목표**: 등록된 회원을 모두 출력한다.

**할 일**

1. 회원이 한 명도 없으면 "등록된 회원이 없습니다." 출력.
2. 반복문으로 `printMember` 를 호출한다.

**힌트**

```kotlin
fun selectAll(members: Array<Array<String>>) {
    if (memberCnt == 0) {
        println("등록된 회원이 없습니다.")
        return
    }
    for (i in 0 until memberCnt) {          // memberCnt 까지만!
        print("${i + 1}. ")
        printMember(members[i])
    }
}
```

> **팁**: `members.size`(= 정원)까지 돌면 아직 안 채운 빈 칸이 `[이름] , [이메일] , [연락처] ` 처럼 출력됩니다. 등록된 인원인 `memberCnt` 까지만 도는 것이 깔끔합니다.
> `for (i in members.indices)` 는 `0 until members.size` 와 같습니다. 여기서는 `memberCnt` 가 기준이므로 `indices` 를 쓰면 안 됩니다.

**확인**: 등록한 회원만 빠짐없이, 빈 칸 없이 나오면 성공.

---

### Step 6. 정보 수정

**목표**: 이메일로 회원을 찾아 이름·이메일·연락처를 새 값으로 바꾼다.

**할 일**

1. 이메일을 입력받아 `findIndex` 로 인덱스 `idx` 를 찾는다.
2. `idx == -1` 이면 "찾으시는 회원이 없습니다." 후 `return`.
3. 새 이름·이메일·연락처를 입력받아 `members[idx]` 를 덮어쓴다.
4. "수정이 완료되었습니다." 출력.

**힌트**

```kotlin
fun updateMember(members: Array<Array<String>>) {
    println("수정할 회원의 이메일을 입력하세요.")
    val email = readln()

    val idx = findIndex(members, 1, email)
    if (idx == -1) {
        println("찾으시는 회원이 없습니다.")
        return
    }

    println("현재 정보 → ")
    printMember(members[idx])

    println("새 이름을 입력하세요.")
    members[idx][0] = readln()
    println("새 이메일을 입력하세요.")
    members[idx][1] = readln()
    println("새 연락처를 입력하세요.")
    members[idx][2] = readln()

    println("수정이 완료되었습니다.")
}
```

> `members[idx][0] = readln()` — 입력받은 값을 변수에 담지 않고 배열 칸에 바로 넣었습니다. `readln()` 의 반환값이 `String` 이라 그대로 대입됩니다.

**확인**: 수정 후 조회하면 바뀐 정보가 나오면 성공.

---

### Step 7. 회원 삭제 + 당기기

**목표**: 이메일로 찾아 삭제하고, 뒤 회원들을 한 칸씩 앞으로 당겨 빈자리를 없앤다.

**할 일**

1. 이메일로 `idx` 를 찾는다. 없으면 `return`.
2. `idx` 부터 `memberCnt - 1` 직전까지, **다음 회원을 현재 자리로 복사**한다.
3. `memberCnt--`.
4. 당긴 뒤 마지막에 남는 꼬리 데이터를 `""` 로 정리한다.

**힌트 (당기기 — 이 Step의 핵심)**

```kotlin
fun deleteMember(members: Array<Array<String>>) {
    println("삭제할 회원의 이메일을 입력하세요.")
    val email = readln()

    val idx = findIndex(members, 1, email)
    if (idx == -1) {
        println("찾으시는 회원이 없습니다.")
        return
    }

    // 당기기: idx 뒤의 회원들을 한 칸씩 앞으로
    for (i in idx until memberCnt - 1) {
        members[i][0] = members[i + 1][0]
        members[i][1] = members[i + 1][1]
        members[i][2] = members[i + 1][2]
    }

    memberCnt--

    // 꼬리 정리: 당기고 남은 마지막 칸을 비운다
    members[memberCnt][0] = ""
    members[memberCnt][1] = ""
    members[memberCnt][2] = ""

    println("삭제가 완료되었습니다.")
}
```

> **순서에 주의**: 당기기 → `memberCnt--` → 꼬리 정리 순서입니다.
> `memberCnt--` 를 먼저 하면 당기기 범위가 한 칸 모자라 마지막 회원이 사라집니다.
> `until` 은 끝을 **포함하지 않습니다.** `idx until memberCnt - 1` 은 `i + 1` 이 최대 `memberCnt - 1` 이 되도록 하는 범위입니다.
>
> 💡 **더 짧게 쓰기(선택)**: 세 줄 복사 대신 `members[i + 1].copyInto(members[i])` 한 줄로 쓸 수 있습니다.
> 꼬리 정리도 `members[memberCnt] = Array(3) { "" }` 로 행 전체를 새 배열로 갈아 끼우면 한 줄입니다.

**확인**: 가운데 회원을 지워도 목록이 빈칸 없이 이어지고, 현재 인원수가 줄면 성공.

### Step 8. `main` 조립 + 마무리 다듬기 (완성!)

**목표**: Step 1의 빈 `when` 갈래를 실제 함수 호출로 채워 완성한다.

**힌트**

```kotlin
while (true) {
    when (printMenu()) {
        1 -> addMember(members)
        2 -> selectEmail(members)
        3 -> selectName(members)
        4 -> selectAll(members)
        5 -> updateMember(members)
        6 -> deleteMember(members)
        7 -> {
            println("이용해주셔서 감사합니다.")
            return
        }
        else -> println("올바른 번호를 입력하세요.")
    }
}
```

> 실행할 코드가 한 줄이면 중괄호 없이 `->` 뒤에 바로 씁니다.

**점검 항목**

- [ ] 현재 인원/정원(`memberCnt`/`totalCnt`)이 메뉴에 정확히 표시되는가?
- [ ] 정원이 꽉 찼을 때 추가가 막히는가?
- [ ] 이메일이 중복되면 추가가 막히는가?
- [ ] 삭제 후 전체 조회 시 빈칸이나 중복 회원이 안 나오는가?
- [ ] 없는 회원을 조회/수정/삭제해도 프로그램이 멈추지 않는가?
- [ ] 문자열 비교에 `equals` 대신 `==` 를 썼는가?
- [ ] 검색 코드를 다섯 군데 복사하지 않고 `findIndex` 하나로 처리했는가?

## 7. 자바 버전과 달라진 점 정리

|자바|코틀린|
|---|---|
|`String[][] m = new String[n][3];`|`val m = Array(n) { Array(3) { "" } }` — **`new` 없음**|
|채우지 않은 칸은 자동으로 `null`|빈 값을 무엇으로 채울지 **내가 정한다** (`""` 또는 `arrayOfNulls`)|
|`static int memberCnt = 0;`|파일 최상위 `var memberCnt = 0`|
|`email.equals(m[i][1])`|`email == m[i][1]` — **`==` 가 내용 비교**|
|`switch` + `break`|`when` (`break` 없음)|
|`for (int i = 0; i < n; i++)`|`for (i in 0 until n)`|
|`Scanner` + `nextInt()` 뒤 버퍼 비우기|`readln()` — **버퍼 문제 자체가 없음**|
|`System.out.println("[이름] " + m[0])`|`println("[이름] ${m[0]}")` — 문자열 템플릿|
|`public static void main(String[] args)`|`fun main()`|
|`m.length`|`m.size`|

> **가장 크게 줄어든 코드**: 자바 버전 Step 8의 "Scanner 버퍼 문제"가 통째로 사라졌습니다. `readln()` 은 항상 한 줄을 통째로 읽기 때문입니다.
> 숫자를 읽을 때만 `readln().toInt()` 로 변환하면 됩니다.

## 8. 최종 완성 체크리스트

- [ ] 요금제 선택 → 정원만큼 2차원 배열 생성 (`Array(n) { Array(3) { "" } }`)
- [ ] 최상위 `var` 로 `totalCnt` / `memberCnt` 관리
- [ ] 메뉴 1~7 반복 (`while (true)` + `when`) + 7 종료
- [ ] `findIndex` 검색 함수 하나로 중복검사·조회·수정·삭제 모두 처리
- [ ] 추가(정원·중복 검사) / 이메일 조회 / 이름 조회 / 전체 조회
- [ ] 수정 / 삭제(+당기기+꼬리 정리)
- [ ] 반복 범위는 `totalCnt` 가 아니라 `memberCnt` 기준
- [ ] 문자열 비교는 `==`

## 9. 개선 & 도전 과제

**먼저 다듬으면 좋은 점**

1. **숫자가 아닌 입력 막기** — 지금은 메뉴에서 `abc` 를 입력하면 예외로 죽습니다.
   ```kotlin
   return readln().toIntOrNull() ?: -1
   ```
   `-1` 은 `when` 의 `else` 로 떨어져 "올바른 번호를 입력하세요."가 나옵니다.

2. **빈 입력 막기** — 이름이나 이메일에 그냥 Enter를 치면 `""` 가 저장됩니다.
   `if (name.isBlank()) { ... return }` 으로 걸러 보세요.

3. **자료형 이름 줄이기** — `Array<Array<String>>` 을 매번 쓰기 번거롭습니다. 파일 최상위에 별명을 붙일 수 있습니다.
   ```kotlin
   typealias Members = Array<Array<String>>

   fun addMember(members: Members) { ... }
   ```

4. **열 번호를 상수로** — `findIndex(members, 1, email)` 의 `1` 이 무슨 뜻인지 한눈에 안 보입니다.
   ```kotlin
   const val NAME = 0
   const val EMAIL = 1
   const val PHONE = 2

   findIndex(members, EMAIL, email)   // 훨씬 읽기 좋다
   ```

**확장 도전 과제**

1. **동명이인 처리** — 이름 조회 시 일치하는 회원을 **모두** 출력하도록 바꿔 보세요. (찾는 즉시 `return` 하지 말고, 몇 명 찾았는지 세면서 끝까지 돌기)
2. **정렬해서 출력** — 전체 조회 시 이름 순으로 정렬해 보세요. (`sortedBy { it[0] }`)
3. **부분 일치 검색** — 이메일이 정확히 같을 때만 찾지 말고, `contains` 로 포함 검색을 지원해 보세요.
4. **회원을 클래스로** — `Member` 클래스(이름/이메일/연락처)를 만들어 `Array<Member?>` 로 관리해 보세요. `members[i][1]` 대신 `members[i].email` 이 되어 훨씬 읽기 좋아집니다. (객체지향을 배운 뒤에)
5. **리스트로 바꾸기** — 고정 크기 배열 대신 `MutableList<Member>` 로 바꾸면 정원 제한과 **당기기 코드가 통째로 사라집니다.** `remove` 한 줄이면 끝입니다. 이 차이를 직접 확인해 보세요.
6. **파일 저장** — 프로그램을 꺼도 회원이 유지되도록 파일로 저장/불러오기.
