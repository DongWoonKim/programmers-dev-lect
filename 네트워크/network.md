# AWS 인프라를 위한 네트워크 기초

## 1. IP 주소

### 1-1. 생김새

IPv4 주소는 32비트이다.
8비트씩 4덩어리로 나누고, 점으로 구분한다.

```
192.168.10.25
```

- 한 덩어리를 옥텟이라 부른다.
- 옥텟 하나는 0 ~ 255
- 전체 개수는 2^32 = 43억개

#### 옥텟을 2진수로 보기

10진수 172는 아래와 같이 표기할 수 있다.
```
자릿값  100  10  1
       1    7   2 -> 1 * 100 + 7 * 10 + 1 * 1 => 172
```

2진수
- 자릿값이 10배씩이 아닌 **2배씩** 커진다.
- 각 칸에는 **0 또는 1만** 들어간다.

```
128  64  32  16  8  4  2  1
 1    0   1   0  1  1  0  0

 -> 128 + 32 + 8 + 4 = 172
```

그래서 172 = 10101100 이다.
